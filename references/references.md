# References

This is the canonical AMA-style reference list for Algorithm32, the production
Flat application, and `flat32`. Source comments and fixture citations use the
numbered entries maintained here.

The entries below include the consolidated extraterrestrial references used
by current facts or planned official experiments. A bibliography entry records
source identity; it does not admit retained bytes to the canonical download
set, grant redistribution permission, or turn the rolled-back experimental
implementation into a production dependency.

Research-only payloads for entries 1--7 and 10 are retained under
`downloads/extraterrestrial-sources-2026-07-12/`. Their bytes match the listed
SHA-256 values, but none is admitted to `downloads/manifest.json`; publication
and redistribution remain blocked pending file-by-file provenance, license,
and consumer review. The ASD v2.0.0 bytes are embedded in the retained LIME
release archive and have the same research-only status.
