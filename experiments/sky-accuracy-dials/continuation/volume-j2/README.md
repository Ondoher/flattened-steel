# Positive-height second-order pilot

This contained CPU diagnostic evaluates independent incoming first-order light
at eight points along two frozen C0 viewing rays. It separates ground-hit,
inward-escaping and outward angular intervals, atmospheric/direct-ground light,
and final Rayleigh/Mie scattering. No production source is modified.

The [attribution plan](../../../../agents/topics/poc-experiments/engineering-studies/sky-accuracy-dials/attribution-plan.md#positive-height-second-order-pilot)
owns its prospective predictions, 4 MiB retained allocation, one CPU-hour cap,
measured expansion gate and cumulative C5 resource admission. Use the original
C0-registered Node binary. Each pilot invocation creates a new immutable run.

```text
node experiments/sky-accuracy-dials/continuation/volume-j2/run.mjs proof
node experiments/sky-accuracy-dials/continuation/volume-j2/run.mjs pilot tmp/experiments/sky-accuracy-dials/runs/00099-c0-registration agents/topics/poc-experiments/engineering-studies/sky-accuracy-dials/attribution-plan.md
node experiments/sky-accuracy-dials/continuation/volume-j2/run.mjs angular tmp/experiments/sky-accuracy-dials/runs/00099-c0-registration agents/topics/poc-experiments/engineering-studies/sky-accuracy-dials/attribution-plan.md
```

The pilot retains compact incident values and empirical allowances, exact
geometry, source/plan snapshots, independent symmetry checks, manufactured
proofs and resource measurements. A passed incident or boundary-limit check
does not establish angular convergence, final viewing-ray radiance or Kider
accuracy. Full component diagnostics are bounded to eight unresolved witnesses;
all incident nonresolution remains present in the compact evidence.

The angular command consumes the fixed accepted pilot and fine ground reference.
It completes the registered 2 x 2 radial/azimuth comparison at six positions,
retaining exact signed interaction vectors and the prospective additive-law and
near-surface-limit predicates. It does not assume that more samples or a lower
interaction norm alone establish true numerical accuracy.
