# Matched H fifth and sixth orders

`runMatchedSixOrders(C0, planPath, caseId, prefixRun, predictionRun)` supports
raw `matched-h-n6` and `matched-p55-n6`, with exact original parents `00103-c-r0-scr`
and `00132-c-d55-raw`. P55 additionally requires a separately sealed
`matched-p55-predict` record with the original transfer-plan identity, all four
admitted input groups and both registered models. The exact owning plan is
`agents/topics/poc-experiments/engineering-studies/sky-accuracy-dials/matched-order-plan.md`.

The original S80/T160/I512, P48/W27 or P55/W27 request still specifies N4. Unchanged
`orders/driver.js` executes actual J1–J6 and L1–L5 under a separate six-order
contract. Only channels 0/8 execute; all forty original C0 probe rays are retained.
This is a partial spectral diagnostic, without full-boundary qualification.

`prepareMatchedOrderViews` reconstructs H's complete original sparse union,
including reference-only taps and P55's four original ground-probe stencils,
in exact original order. `evaluateMatchedOrderViews`
retains original screen selectors in the six-order spectra, and grouped
seven-method probe envelopes through actual N6. Original N1–N4 fields, Float32
cumulative fields, complete N4 spectra and all original cumulative/grouped
envelope rows must match the immutable parent exactly. The raw driver and all
old source modules remain unchanged.

The original fixed-field four-order evaluator computes the first four envelopes.
A second invocation of its grouped density callback maps temporary slots
1/2/3/4 to actual N3/N4/N5/N6. The actual higher fields are left-folded in
Float32 before reconstruction. Duplicate N3/N4 slots are exact parity witnesses;
their evaluations are charged and their slot derivations are retained. They are
not mislabeled as new physical third/fourth orders. Six actual-order method rows
use the new `sky-matched-order-diagnostics-v1` contract.

The bounded payload travels inside `compilerReport.matchedOrderDiagnostics`.
The existing host validates the six-order binary spectrum and bounds metadata
at 1 MiB; the owning runner strictly validates the additional payload, exact C0
identities, exhaustive row inventory and all seven-method envelope equations
before accepting the channel. The original four-order diagnostic decoder is
never asked to accept N5/N6. Failed browser payloads and prefix mismatches remain
in the newly failed run.

Each attempt charges the existing C5 ledger: at most 6 MiB, fifteen GPU-job
minutes, two minutes reserved for finalization, and the original attempt/time,
memory and storage ceilings. The host owns Chrome termination and loopback-server
closure; the run owns authenticated scratch removal and immutable sealing. Exact
plans, source bytes, original inputs, runtime identities, fields, spectra,
prefix evidence, work and predictions retain their derivation chain. No full
texture package or scene cache is retained.

Capture acceptance means complete execution and exact prefix parity. The held
positive-increment and finite-ratio predictions retain independent states.
Unresolved fixed-field envelopes prohibit quantified tail additions. The physical
P1/P2-substitution prediction remains explicitly unresolved for separate assessment.
Two additional orders establish neither recurrence accuracy nor an infinite-tail
bound. P55's altitude-response assessment follows its separate transfer
registration. Factored-species execution is outside this implementation.
