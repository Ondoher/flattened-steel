# Shared-reference error contrast

The descriptive contrast compares candidate and matched-control absolute errors
against one common uncertain physical reference. Its reference contribution
can cancel exactly when both candidates lie on the same side. Calculate the
piecewise-linear extrema at the reference interval endpoints and its two
field-value breakpoints, then widen by the candidate/control field allowances.

This improves the precision of a descriptive direction statement without
weakening or replacing the separately frozen 80% error-reduction predicate.
An unadmitted reference always leaves the scientific direction unresolved.
The focused proof samples independent reference/field uncertainty boxes and
checks that every witnessed true contrast remains inside the reported interval.
