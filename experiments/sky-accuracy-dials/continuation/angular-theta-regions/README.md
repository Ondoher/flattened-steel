# Saved theta-node regional attribution

The [prospective plan](../../../../agents/topics/poc-experiments/engineering-studies/sky-accuracy-dials/angular-theta-regions-plan.md)
registers one `angular-theta-regions-v1` diagnostic. Its only incident inputs
are the complete accepted batches from 00220 and 00221; 00222 supplies the
assessment identifying the unresolved response.

```text
node experiments/sky-accuracy-dials/continuation/angular-theta-regions/run.mjs <C0>
```

`readThetaRegions(registration)` returns the original theta input, pilot/fine
documents and authenticated in-memory nodes, the prior assessment identity,
and complete consumed parent/source identities. It pins all three parent seals,
checks their original plans and input payloads, requires complete physical
admission, and rechecks every consumed source and original Node identity.
It does not calculate the registered regional targets.

`runThetaRegions(C0)` writes one immutable `at-regions` record. A previous
attempt with this package or case identifier blocks another attempt even when
it failed. The current C5 allocation and campaign ledger remain authoritative.
Retained output is capped at 2 MiB and five CPU-job minutes, with thirty seconds
and 768 KiB reserved for finalization. Actual source/metadata bytes are forecast
before allocation and every write enforces the cap and disk-floor guard.

The runner preserves the exact plan, compact batch pointers, proof, regional
assessment and report. It uses the authenticated 00210 source snapshot with
complete deltas and reauthenticates all source/control parents and the Node
executable at finalization. Original incident arrays stay in their immutable
runs; this diagnostic writes no scratch arrays and starts no worker, incident
integration or GPU job.

The numerical helper separately checks full row replay, partition unity,
mirror contributions and regional reconstruction. Its focused manufactured
`thetaRegionsProof()` is retained before evaluation. Execution or
authentication failures seal a failed diagnostic with an unresolved conclusion;
failed scientific predictions remain explicit evidence. The full experiment
type check precedes execution. Formal review remains deferred under the
owner's direction.

This partitions the response between two saved quadrature rules. It does not
identify absolute error, isolate polar from azimuth refinement, or reopen the
preceding reference admission.
