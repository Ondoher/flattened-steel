# Angular background attribution

Run the pinned Node with `run.mjs C0Registration` to reuse the immutable
00161/00162 incident nodes at the selected morning point. The
[plan](../../../../agents/topics/poc-experiments/engineering-studies/sky-accuracy-dials/angular-background-plan.md)
owns the fixed diagnostic background, exact discrete-response decomposition,
six predictions and resource bounds. The finest retained mean is not called
an admitted angular oracle. No new optical integration, GPU work or Kider
comparison is performed. Formal source review is deferred.

An optional second CLI argument supplies the preceding angular-background run
and selects the [smooth angular-region diagnostic](../../../../agents/topics/poc-experiments/engineering-studies/sky-accuracy-dials/angular-regions-plan.md).
It exactly replays the prior decomposition, then partitions directional
responses using fixed Sun, radial-tangent and remaining-region weights. Both
mirrored directions retain their own phase weights. This is a diagnostic
partition of existing responses, not a replacement angular quadrature.
