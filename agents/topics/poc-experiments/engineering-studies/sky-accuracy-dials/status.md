## Reproduce Or Extend

Use Node with the existing repository dependencies and Chrome installation.
Every evidence command allocates a new immutable run. Run GPU commands serially.
All paths below are repository-relative; substitute exact accepted parent paths.

```text
node experiments/sky-accuracy-dials/run.mjs storage
node experiments/sky-accuracy-dials/run.mjs proof
node experiments/sky-accuracy-dials/run.mjs run baseline screen
node experiments/sky-accuracy-dials/run.mjs predict-count <coarse> <medium> <target-case> <floor>
node experiments/sky-accuracy-dials/run.mjs run <target-case> full 30 <prediction-run>
node experiments/sky-accuracy-dials/run.mjs assess <prediction-run> <target-run>
node experiments/sky-accuracy-dials/run.mjs run segmented full 2,4
node experiments/sky-accuracy-dials/run.mjs predict-view <segmented-2,4-run> <floor>
node experiments/sky-accuracy-dials/run.mjs run segmented full 8 <prediction-run>
node experiments/sky-accuracy-dials/run.mjs representation-contrast <baseline> <candidate> <floor>
node experiments/sky-accuracy-dials/run.mjs residuals <baseline-full> <candidate-full>
node experiments/sky-accuracy-dials/run.mjs summary
node experiments/sky-accuracy-dials/run.mjs verify <run>
node experiments/sky-accuracy-dials/orders/run/execute.mjs baseline all-times
node node_modules/typescript/bin/tsc -p experiments/sky-accuracy-dials/jsconfig.json
```

`cases.mjs` owns supported intervention names; `numerics/profile.js` owns count
admission. Predictions reject coupled single-factor ladders and unsupported
future levels. `full-campaign <floor>` reproduces the full serial source,
transport, combined and segmented campaign. The original fixed prediction floor
is run `00006-prediction-floor`; its derivation is retained and is not a measure
of measurement uncertainty.

Further physical-model work, other atmospheres, true horizon/sunset, full-spectrum
N6 qualification and production promotion are outside these completed claims.
The experiment remains contained and its generated evidence immutable.
