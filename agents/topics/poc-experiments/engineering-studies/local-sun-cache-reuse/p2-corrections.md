## Selected Matrix

Capture: `00041-p2-prec-sel`, N4/W27/F68/Native15, 570 spatial nodes,
ten complete fields per angle at 0/17/45/90/135/180/271 degrees.

- All 1,844,696,700 measured field scalar comparisons pass, as do every pure-order/cumulative reconstruction, strict axis/off-axis rotation, CPU/GPU radiance/transmission and equivalent-ray comparison.
- All 96 world-fixed and 96 equivalent rotated rays per angle are covered. Admission is limited to these measured directions and fixed-offset poses, not arbitrary rays, continuous angles or horizontal translation.
- Two-part GPU endpoints pass the unchanged 0.01 m gate; worst discrepancy is 3.7253e-9 m. A single FP32 readback still cannot represent all these endpoints within one centimetre.
- Every fresh/reused PNG is byte-identical: maximum and p95 differences are zero at all seven angles. The blink and rotation clip remain diagnostic visual evidence, not full temporal qualification.
- The declared cylinder radius is 8,210,202.5934 m; every original radial node remains, and fifteen new outer nodes preserve the last-interval density. Logical bytes across all ten measured fields are 1,054,112,400, twice the original 285-node inventory. One full cumulative field is 149,590,800 bytes. These are logical payload sizes, not measured peak GPU memory or a completed app budget gate.
- Compared with original-policy fresh rays already inside the old cylinder, the largest spectral radiance change at zero rotation is 0.25242222. Enlarging the construction boundary changes the result; this difference is recorded separately from same-policy reuse. It does not prove which policy is physically more accurate.
- Physical axis-approach checks still fail: a one-millimetre approach can expose the existing angular reconstruction's azimuth dependence. Rotational covariance does not remove that discontinuity. The intended viewing paths remain more than 4.35 million metres from the source axis; no independent physical-accuracy or axis-continuity claim is made.
- Selected-run wall time was 355.861 seconds. Per-angle cache build plus complete-field readback measured 1,502.5-3,261.4 ms, with zero GL errors. The wall time includes bundling, shader compilation, probes, encoding and cleanup; it is not a warm-app performance benchmark.
