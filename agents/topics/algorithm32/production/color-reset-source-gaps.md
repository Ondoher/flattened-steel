# Production Color Reset Source Gaps

Status: current authority and citation backlog; investigation deferred.

This document is the canonical list of source and first-party experiment
authority missing from the [Production Color Reset Design](color-reset-design.md).
It records which contained increment introduced or selected each fact so later
research can begin from the correct evidence boundary.

This register does not make a source or run authoritative. A third-party source
becomes citable only after registration in
[`/references/references.md`](../../../../references/references.md), including
the required locator, version, payload identity, license, and transformation
provenance. A contained run becomes citable only after satisfying the
[Official Experiment Promotion Checklist](../experiments/promotion-checklist.md)
and registration in
[`/references/experiments.md`](../../../../references/experiments.md).

“Investigation deferred” means the research may occur later, but the affected
production numerical capability cannot pass its authority gate until its row is
resolved or the owning design selects a different valid authority.

tests or official experiment registration where listed above, but searching for

- `q=24` one-pixel presentation calibration;

- maximum rod contribution `0.5`;

- the 152,000-byte package layout and selected GPU readback indices;
- fail-closed selector behavior and atomic lifecycle policy; and
- San Jose as the fixed summer review geometry rather than a light-pollution
  model.
