Status: canonical Step 4.5.2 production-operation classification appendix.
This file classifies the runtime partition from the
[Step 4.5.1 inventory](./helper-ownership-inventory-runtime.md). It selects no
namespace target or migration batch; those decisions are now recorded in the
[runtime target appendix](./helper-ownership-target-plan-runtime.md).

The decisions belong to production source identity
`4aeeb00102d4713f3f31f219cdf9d71092a64d241279fd7e60411f0e84e090af`.
The authoritative row identity is `current path + symbol + role`.

`class-independent` is an ownership finding, not an instruction to export
the operation or create a module for it. `return-to-class` names the current
class whose responsibility, state, lifecycle, or collaborator transaction the
operation exclusively implements.
