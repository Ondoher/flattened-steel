## Decision Contract

Every row preserves its Step 4.5.2 disposition and has one exact semantic
owner. Existing class operations stay on their classes. Returned support
becomes a private instance method on the named existing class unless Step
4.5.5 must first decide a construction callable. Class-independent operations
join cohesive PascalCase namespace modules with one namespace-object export.
No compatibility export, duplicate callable, speculative barrel, or
single-function namespace is planned.

The 25 construction-shaped rows have exact semantic owners but action
`defer-construction-form-to-4.5.5`. That action does not retain or remove a
factory; it prevents Step 4.5.4 from moving the callable ahead of the factory
decision. Non-construction support inseparable from a deferred construction
cohort uses the same atomic `RTF*` batch. Immediate `RT*` batches contain no
construction decision. `RT-R*` rows are no-op retention records.

All returned class support targets instance methods. Newly introduced static
support methods: zero. Existing public APIs remain public only where the
classification already keeps them on their class.
