# Topic Context

This folder owns the small amount of context needed to find and resume work.

## Canonical Documents

- [Repository bootstrap](../../../AGENTS.md) defines the bounded loading and
  continuity rules.
- [Active Topic](../active-topic.md) identifies the current topic and its
  minimal reload sources.
- [Topic Routing](routing.md) maps work to the appropriate documentation area
  when the active route is insufficient.

Bootstrap should remain narrower than discovery: load the active route first,
and consult routing or neighboring topics only when the task calls for them.
