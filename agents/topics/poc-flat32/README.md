# poc-flat32

Explore application interactions and inspect appearance candidates before a
product decision. Existing Flat32 is the temporary JavaScript integration test
bed described by [application roles](../production-app/README.md#application-roles-and-current-status).
Its integration contracts and evidence remain under production-app/runtime-integration.
These exploratory topics do not allocate another prototype or select the
finished app's behavior.

## Focus Areas

- [appearance-review](appearance-review/README.md) — Exploratory captures and qualitative candidate review.
- [interaction-prototypes](interaction-prototypes/README.md) — Unselected control and quality-selection interactions.

Select one focus entry and its task-specific owner. Do not reload every focus.
[Other work topics](../README.md) and [historical documents](../context/topic-migration-archive-index.md)
are navigation, not additional routine context.
