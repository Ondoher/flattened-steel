## New primary guidance: pending parent verification

Direct web opens on 2026-11-05, current WCAG 2.2 Understanding documents. These are informative explanations of criteria, not inspected product screenshots. Advice uses their stated constraints, not visual styling claims. No images from these pages were used as visual precedent.

- W1: [Target Size (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html). 24×24 CSS-pixel target minimum with enumerated exceptions; larger targets can be easier to operate. Supports a floor when considering compact controls, not a 32–36px prescription or conformance claim.
- W2: [Reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html). Addresses preserving information/functionality at equivalent 320px width, with exceptions for content requiring two dimensions. Supports evaluating forms/toolbars at narrow width/zoom; does not dictate Flat's comparison layout or resolve a compliance assessment.
- W3: [Labels or Instructions](https://www.w3.org/WAI/WCAG22/Understanding/labels-or-instructions.html). Inputs require useful labels/instructions; format cues can assist, excessive instructions can burden. Supports visible names, units/format meaning, and avoiding redundant prose. Does not prescribe exact wording.
