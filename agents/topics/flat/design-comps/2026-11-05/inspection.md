## Correction P1 — restore the specified outlined-button roles

**Scope:** all five images. **Status:** sent to parent; repaired images not yet inspected.

Outlined workspace and close commands appear with pale-blue text and pale-blue borders. The spec assigns `#F2F2F2` to ordinary text/borders and uses the pale blue for filled actions, deliberate selection, text edit/disclosure affordances and focus. The source read confirms `button.outline` currently binds both border and text to `--action`.

Parent correction: in `comps.css`, change only `button.outline` border color to `var(--border)` and text color to `var(--text)`, retaining its dark fill, size and radius. This covers Add second view / Single view, closed Configuration, Close, and Close View 2. Keep blue-filled actions and the open Configuration button, blue Edit/disclosure affordances, the active Location rule and blue focus outline unchanged. Rerender the five affected PNGs for a bounded appearance check. No geometry revision or additional scene is requested.

This is fidelity to the supplied color roles, not a finding that the present blue outline is illegible.

## Shared strengths and limits

The dark continuous surface, white structural separators, literal control values and sparse headings produce a coherent family. No new gray surface palette, shadow system or decorative feature category was introduced. Filled actions and open Configuration are visually distinct from fields. The real sky/ground image remains consistent between peer views, with aligned horizons and one hint per scene; no fabricated result or update status appears.

The static captures show unfocused, valid, ready-state controls only. Focus, keyboard behavior, popup dismissal, pointer lock, native option lists, draft retention, asynchronous updates and error recovery were not exercised. The small read-only CSS check confirms the intended focus rule exists, not that it was tested. Image reuse/cropping remains layout illustration and does not verify physical projection at each pane aspect ratio. The parent's empty overflow/containment issue lists support these exact layouts but do not prove arbitrary content, localization, zoom or additional window sizes.

These advisory comps remain proposals. The designer did not change source code, render them, or grant production readiness. Reinspection will address only the shared palette repair and any resulting visible regression against new exact image identities.
